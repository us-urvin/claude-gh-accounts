# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be respectful, assume good intent, and focus on what's best for the people using this tool. Harassment, insults and personal attacks aren't tolerated in issues, pull requests or anywhere else in the project.

To report a problem, contact the maintainer [@us-urvin](https://github.com/us-urvin) privately through a [private advisory](https://github.com/us-urvin/claude-gh-accounts/security/advisories/new), or use GitHub's "Report content" option on the comment. Reports are handled confidentially.
